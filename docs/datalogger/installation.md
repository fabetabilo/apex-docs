#

## Requirements

- Content Manager - Get it from the official link [here](https://acstuff.club/app/)
- CSP v0.2.8 or higher (or use the latest stable version)

## Installation

1. Download the latest release from GitHub

<div class="grid cards" markdown>

-   ![Apex logo](assets/sm.png){ .card-icon }
    
    ---
    
    [:material-download: Download](https://github.com/fabetabilo/apex-logger/releases/latest/download/Apex.zip) · [Source Code](https://github.com/fabetabilo/apex-logger/)

</div>

2. Extract the ZIP file
3. Copy `apps` folder in to your AC root folder `..Steam\steamapps\common\assettocorsa` **manually**

<p align="center">
<img src="../assets/01dragndrop.gif" alt="dragndrop">
</p>


At this point the installation is complete. You can verify that the `apex` app folder exists in both your `apps/lua` and `apps/python` folders.
